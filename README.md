# 當下情境球員價值評估系統（原型）

比賽中換人時機（打席與打席之間），評估「續打 vs 各代打人選」與「牛棚各投手」，
並檢查換人後守備排不排得出來。不做打席中逐球的攻擊策略。

**線上版：https://da-xiong-chen.github.io/baseball_project/**

公開網站是否包含本機修改，以原作者合併與部署為準。下一階段只聚焦 **換打與換投**；球路與資料提示用於解釋候選，不擴充無關分析頁。

### 本次功能更新

- 頁首可選深色／淺色，首次預設深色，記住同瀏覽器的選擇；切換不清除情境或改變推薦。
- 「現任與候選比較」固定基準，呈現差值、階層式理由、兩模型分歧與樣本限制；點選姓名切換人選。
- 換投明細列出後續每位打者的估計及疲勞項，與合計失分價值對照；這是得分期望變化的價值，可為負值，不是實際會失幾分。僅比較接下來最多三棒，不是整場換投最適策略。
- 勝率換算使用「百分點」，價值分數是比較池百分位；原「可信度」在介面標為樣本充分度，不當成排名把握度。
- 歷史估計的慣用手、守位、比較池、疲勞曲線與逐球得分期望表均限制在截止日前。可用名單仍由過去出賽推估，不能冒充官方當日登錄或健康資訊。

## 運作方式

系統採用**集成模型**：以下兩個模型的「每打席預期得分值」各占一半。

```
① 階層式模型   = 投手 8 格球路分布 × 打者對各格的適性 + 打者本身能力 + 投手本身能力 + 左右投打（部分池化）
② 梯度提升樹模擬 = 取投手實際投過的 150 顆球（位置、球種、球速、球數），換上候選打者，
                  以梯度提升樹預測每顆球的結果機率（壞球/好球/揮空/界外/弱擊/強擊），換算成預期得分
當下價值（勝率 %）= 相對聯盟平均打者的得分值 × 此局勢「1 分值多少勝率」
```

打者／投手傾向特徵（揮空、強擊、出棒、得分值）一律先做部分池化再餵給梯度提升樹，處理替補小樣本；
訓練中的球員傾向特徵以 5 折（依比賽分折）out-of-fold 估計，降低同場結果直接進入特徵的洩漏；歷史訓練標籤另外按截止日前資料重建。這不等於所有分布偏差或反事實問題都已解決。

| 檔案 | 內容 |
|---|---|
| `src/load.py` | 讀 Rebas 2024+2025 逐球資料、重建球數、計算每顆球的得分價值（加總後與官方 RE24 相關 0.996） |
| `src/model.py` | 部分池化模型；只用截止日以前的資料，可做歷史回放不偷看未來 |
| `src/roster.py` | 守位能力、當日名單推估、換人後守備檢查 |
| `src/engine.py` | 代打評估、牛棚評估（集成） |
| `src/mlmodel.py` | 梯度提升樹訓練、存檔、投手歷史球模擬 |
| `src/ml_compare.py` | 逐球結果的機器學習演算法比較（含 XGBoost、LightGBM） |
| `src/experiment.py` | 打席開始前評估方法的完整比較實驗 |
| `server.py` | 本機網頁伺服器與 JSON API（標準函式庫） |

**球路格**：球種群（速球 FF/SI、滑卡 FC/SL、曲球 CU、低落 CH/FO/FS）× 高低（coordY < −21 為低球），共 8 格。

**局勢換算**：用歷史資料估計各局勢下 WPA 與 RE24 的比例（1 分值多少勝率），例如 10 局下平手二三壘 1 分 ≈ 21% 勝率，全聯盟平均約 8.6%。

## 研究依據與方法實作

### 前端圖表與分數的技術解讀

操作頁僅保留評估方式、資料範圍、圖表限制與使用限制，技術細節集中於此。下列是目前實作的解讀方式，不是新增研究成果。

- **模型與權重**：階層式模型與逐球模型的得分值依集成權重結合；目前配置通常各占一半，靜態端實際使用匯出資料的 `ml.w`。逐球估計不可用時回退階層式，不能宣稱所有歷史快照都用了完整集成。實作見 `src/engine.py`、`docs/engine.js`。
- **圖表拆解**：攻守共用「現任固定為 0」的差值圖，右側綠色表示較有利，左側紅色表示較不利。換打分項顯示候選減現任；換投逐棒圖顯示現任減候選的失分價值，含疲勞調整。原始雙方数值可展開核對。換打分項只解釋階層式部分，不能加總後直接當成完整集成的勝率差；失分價值是得分期望變化，可為負值，不是實際失分數。
- **誤差細線**：評估表細線來自階層式估計的近似標準誤，再按局勢斜率換算。它不是完整集成的預測區間，也不是候選勝出機率或排名把握度。不可由兩條細線是否重疊直接認定換人效果。
- **比較池與價值分數**：比較池由截止日前資料建立，早季不足時依既有程式回退前一季。打者依打席量，後援依登板場次與先發比例條件選入；詳細條件以 `src/roster.py` 的 `hitter_pool()`、`reliever_pool()` 為準。價值分數是池內相對百分位，同值採中間名次，映射到 1–100；它不是成功機率，也不能跨不同對決當成絕對能力。樣本資格條件不是已驗證的可靠度界線。
- **時間與資格限制**：模型與逐球資料截止日不一定相同，皆排除截止日當天。歷史守位採截止日前完整球季紀錄；實際當日守位、登錄、退場與 DH 存續需人工確認。候選比較不構成完整換人規則檢查。

單一打席結果的隨機性極高，改善幅度小是正常現象（大聯盟研究也是如此）。

## 重要發現

1. **打者 × 球種的「得分」差異，用逐球得分值偵測不到**：雜訊太大，部分池化會把它縮到 0。
   改用穩定得快的成分後，**揮空率**有明確的球路適性訊號（約 160 球就有一半可信度），
   **強勁擊球率**也有，但需要約 800 球。
2. 目前分數主要由**打者整體能力**和**左右投打**決定，球路適性的影響約為每打席 ±0.005 分。
3. 代打的勝率差異通常在 1% 以內；只有高張力局面（延長賽、九局接近比分）才會拉大。
