## 模型與數據

維持階層式及 GBT 各占 50% 的 v4 模型，未重新訓練、未更改分數或門檻。兩組種子共 3,200 次聯合重抽樣及診斷完成，因跨種子區間與門檻判定仍有變動，依使用者指示不採用新區間、不再加算。原研究結果保留供追溯。

正式細線仍只是如實標示的階層式近似誤差。它不是完整集成區間、真實勝出機率或換人因果效益。

## 驗收

- Python 84 項、Node 153 項通過。
- 既有四份數值驗收維持有效，本輪唯讀校驗正式資料、權重及發布來源。
- 實際操作涵蓋代打、無候選提示、球隊換投、場上配置、重整後保存、單日換隊、調度與結果分次揭示，以及同打席完整比較的揭示延續。
- 390px 淺色、320px 深色模型頁沒有整頁橫向溢出；單日分析不顯示或依賴一般／球隊模式。
- 失敗與重試由定向回歸測試驗證；正常模型頁在瀏覽器載入新版採用說明，未觀察到控制台錯誤。

這些是程式與代理操作驗收，並非真人訪談。首次載入傳輸量、公開網路及手機 CPU 效能尚未量測；60 MB 靜態包大小不代表首次下載量。
