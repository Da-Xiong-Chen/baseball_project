# 新使用者任務驗收（尚未執行）

邀請3–5位未參與開發的人，各自操作，不先教每一步。記錄完成／求助／失敗與原因，不以代理驗收代替。

1. 設定八局落後一分、一出局二壘有人，比較現任與兩名代打；請使用者指出基準、較有利人選與接守限制。
2. 配置九棒與投手，套用後進行換投評估；請使用者說明候選是否等於官方今日可上場名單。
3. 找2025/09/20台鋼六局下案例，先說明模型提示，再揭示實際調度和結果；請使用者回答能否據此證明另一換投選擇更好。
4. 找模型驗證結論，請使用者說明區間跨零與0.18%誤差減少的意思。

每人記錄：裝置、任務、完成時間、第一個卡點、是否求助、誤讀內容、建議。若有阻斷或共同誤讀，優先調整互動與資訊順序，再回歸，不只是追加說明。
