# 模型不確定性計算與跨種子診斷結果

主種子流與獨立種子流均完成8個月份、每月200次，各1600次，共3200個有效checkpoint；共176個預先凍結的代打／換投案例。兩流種子範圍不重疊，配對抽樣雜湊不同；逐案例、候選、資料截止日、種子與數值檢查通過。

## 跨種子尾端變化

以每個案例所有固定候選的2.5%與97.5%端點最大差，彙整176案例：

- 中位數：0.301992 百分點。
- 第90百分位：1.027468 百分點。
- 最大值：1.837521 百分點。
- 至少一位候選跨零分類改變：36 個案例。
- 至少一位候選跨1百分點分類改變：48 個案例。

完整候選分位數、排序次數、提示比例、150→200與200→合併400次變化，見 `cross-seed-diagnostics.json`。

## 採用判定

本階段完成計算與診斷，尚未正式採用新的模型區間；正式0.5／0.5權重及網站分數不變。原規格未預註冊數值穩定通過閾值，不能事後挑選剛好通過的閾值。須依上列漂移與個案判讀，明列仍需增補的證據，再決定是否足以支持正式呈現。計算數量達標不等於尾端穩定或覆蓋率通過。

這些分位數是條件於已觀察標籤與固定候選的重新擬合變動，並非反事實換人效益、未來打席預測區間或經實測驗證的覆蓋率。名單、資格與健康不確定性未賦予機率。首選次數及提示比例只表示重抽樣穩定性，不是真實勝出機率。
