# 攻守比較圖與文字精簡

2026-10-04。未修改模型、評分、候選選取與資料。

- 換打「優勢來源」加入本身能力、球路適性、左右投打差值圖。正差值綠色、負差值紅色，所有候選使用相同尺度；缺少候選或現任分項時顯示資料不足，不補零。
- 圖表比較的是候選減現任的階層式分項，單位分／打席，保留短註解避免誤認為完整集成分數的拆解。換投保留既有逐棒圖，攻守上方仍有共同勝率差值圖。
- 刪除候選卡反覆出現的「排序僅供參考」、模型差值段落、比較池人數與重複方法長文。資料有限、模型分歧、難以區分及資料警示保持可見；樣本仍可展開。
- 守備提醒縮成「接守：姓名 · 守位（另需 1 人）」、「無人接守守位」等，保留替補姓名、接守位置、額外消耗與不可接守限制。疲勞提示保留。
