## 修正範圍

- 720 場、415 個來源球員 ID；六組跨年異名依 ID 串接，兩位林子崴仍分開。逐球採實際投手、打者與捕手，保留未知手別及無效球速的來源紀錄。
- 打席開始與結束的參與者分開。24 個打席的開頭與摘要參與者不同；回放不提前使用後來換上的人。時機結果排除打席中換人的混合 RE24，決策覆蓋仍保留。
- 九個 v5 模型全部重訓，固定種子、截止日與 0.5 集成權重。未知手別採雙側平均；不捏造資料，也不把條件式接守備案升級為已確認資格。
- API、JavaScript、靜態資料、舊名單遷移與批次檢查一起更新；全產品名稱為「一球兩面 | 臨場用人決策」。
- 實際瀏覽器測試找到並修正：回放時間列漏載未登板候選的姓名，以及未知手別被誤寫成異側對戰。這兩項修正只改呈現，不修改模型數值。
