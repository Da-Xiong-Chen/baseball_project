## 修改與依據

- 首次開啟改為淺色：HTML 在 JavaScript 執行前即為淺色，主題初始化同步修改；主題按鈕初始文字為「深色」，表示下一次切換。已有深色／淺色偏好繼續沿用，不覆寫使用者選擇。儲存被拒絕或損壞偏好時回到淺色，當次仍可切換。
- 實際選「陳冠宇」後離開、返回單日頁，原先被重設為排序第一位；現在在當次頁面工作期間，按球隊與投／打分類記住選擇。重新載入名單時只還原仍存在的人選；不擴充成新的跨裝置或永久設定。原本「存成預設／載入預設」仍負責跨次開啟的明確保存。
- 實際輸入歷史投手球數 −1，畫面警告無效但按保存仍顯示成功。現在保存前驗證 0–160 整數、已載入人選，失敗時聚焦球數並保留原預設；打者模式不讀取隱藏的投手球數，保存為 0。未更動疲勞曲線或計算方式。

沒有重排既有導覽或重新配色；目前淺色白底、藍色操作與綠紅比較圖保持一致。搜尋無匹配已清楚提示且保留選取，未為改版而增加重複按鍵。
