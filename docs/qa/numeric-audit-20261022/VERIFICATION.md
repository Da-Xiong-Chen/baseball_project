# 網站數值呈現驗收（2026-10-22）

## 結論

本輪核對目前封版網站的全部 680 份 JSON，共 1,847,999 個數值；未發現非有限數值、配球比例越界、單位換算或正負方向錯誤。核對差值時，依匯出器保留六位有效數字的規格計算誤差界線，不把分別四捨五入後的微小殘差誤判為模型計算錯誤。

已修正顯示問題，模型、資料、排序、建議門檻與簡報檔案均未改。這是 PR／本機版本的數值與程式呈現驗收，尚不能取代公開網站發布後的瀏覽器視覺與操作驗收。

## 本輪修正

- 配球差異原有 47 筆非零值會顯示成帶符號的 `+0.0` 或 `-0.0`。改以「增加／減少不到 0.1 百分點」保留方向；非常小的非零配球比例顯示 `<0.1%`。差值提示說明以未四捨五入比例計算，避免觀眾用畫面上已取位的兩個百分比相減而誤認不一致。
- 實際資料中有極小負失分價值被顯示為 `-0.000`；顯示精度內統一為 `0.000`。差異與 WPA 等有方向的變動則以「增加／減少不到指定精度」呈現。
- 樣本缺值不再經 `Math.round(null)` 變成 0 球，改顯示 `—`；有效零樣本仍顯示 0。樣本統一使用千分位。無效的價值分數不顯示為正常的 1–100 分；圖表尺度只納入有限數值，避免一個缺值讓整張圖出現 NaN。
- 時間軸 WPA 缺值不再因 `null * 100` 顯示為測得的 0。資料中的 WPA 是比例，顯示時只乘 100 一次換成百分點。
- 模型驗證明細明確標為「MSE 差值（基準－模型）」及其同單位區間；與主圖的相對誤差改善百分比區分。例如正式時間檢查為 MSE 差值約 +0.000406、相對改善約 0.18%，兩者不是同一單位。
