# 攻守現任與候選統一圖表

2026-10-04。攻守候選卡共用「與現任比較」展開標題，以及同一個圖表產生函式：候選長條、現任基準線、雙方数值、綠／紅圖例、零中線與共同尺度。上方四人勝率差值總覽保持原格式。

換打分項改顯示候選與現任各自的能力／適性值，越高越有利；換投逐棒失分價值越低越有利。綠紅依相對現任的優劣判斷，不依候選值正負判色。不同指標各自共用候選尺度，不將分／打席與勝率百分點混為同一單位。換打仍只拆解階層式部分。

缺少候選分項顯示資料不足；缺少現任基準顯示未提供並使用中性色，沒有虛構基準。模型、評分、候選上限及警示未改動。
