## 本輪修正及理由

1. **預設保存的真實回饋**：寫入後讀回核對，拒絕靜默丟棄時不再誤報成功。進階設定儲存失敗仍在當次頁面生效，恢復可保存時給出成功提示。
2. **損壞預設記錄**：讀取時確認為物件；字串、陣列、數字、null與無效JSON不再造成保存崩潰，也不覆寫損壞原記錄。此情況當次頁面仍可操作。
3. **預設比分驗證**：負數、空白、小數與無窮值不能存成預設；原有效預設保留。實際瀏覽器先保存0:0，再輸入−1並保存，正確拒絕；載入與重新整理仍為0:0。
4. **回測敘述範圍**：卡片結論來自全聯盟的summary，並非單隊檢驗，現在直接標示「全聯盟回測」。平均RE24差異不再寫成「確實比較容易失分」，避免將失分價值與事件機率混為一談；方法說明保留觀察結果不能證明換人有效的限制。
5. **換投時間指標語意**：「換投時也建議」包含較早已有建議的情況；「首次建議在同一打席」只計第一次建議就在實際換投時。以統一資料為例，兩值為90與23，本來就不同。新標籤與說明分清楚兩者，並標示提前建議中位數的適用範圍。數據與演算法未改。
6. **揮空負零**：真實API歷史明細仍出現「揮空−0.0」，改用既有數字格式化函式，保留一位小數與原色彩邏輯，僅去除四捨五入後的負零。

預設保存三項問題均先新增失敗測試再修正。回測語意以現有timing_backtest.py的summarize／pen_timing實作及timing-2025.json交叉確認，不推論新模型效果。
