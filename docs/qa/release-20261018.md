## 判定

本機已驗證的功能可作比賽展示與靜態發布候選，沒有發現尚未修復的受測功能失敗。**尚不能宣告公開上架全部條件完成**：2025 守位資料的對外使用範圍、實體手機與 Safari，以及正式部署後驗收仍待確認。這是驗收範圍，不是保證所有未來情境都沒有問題。

## 實際補齊的項目

1. **全頁共用的資料出處**：新增預設收合的「資料與使用說明」，不必先完成評估才找得到。保留歷史資料年份、Rebas ODC-By、ldkrsi MIT 與官方資料來源；MIT 全文副本隨靜態網站提供，內容與原檔一致。授權連結不等於專案取得了額外公開使用許可。
2. **保存方式**：簡短說明主題、群組、名單與預設存在此瀏覽器，清除網站資料會移除，沒有跨裝置同步。沒有加入帳號、追蹤工具或第三方前端依賴。
3. **頁面基本資訊**：補入中文搜尋描述及停用 JavaScript 時的指引；啟用 JavaScript 的使用者不會多看到這段。
4. **可重複的發布檢查**：`scripts/prepare_site.py` 檢查 HTML 引用、CSS 資源、449 份 JSON、回放／配球索引、重複 ID、根目錄絕對路徑與越界路徑。NaN／Infinity 不是合法 JSON，會直接阻擋。可另外產生乾淨發布包與 SHA-256 清單；拒絕覆寫既有輸出，且不執行網路或 Git 操作。
5. **文件同步**：README 改為目前三個功能頁、四人比較與官方姓名連結的真實操作；標明早期兩人畫面檢查只屬歷史紀錄。協作指南修正「守位資料不在 GitHub」與表格「已提供」互相矛盾的前言，未改協作與 PR 規則。本機發布包與執行暫存檔加入忽略清單。

資料出處核對：[Rebas 官方專案](https://github.com/rebas-tw/rebas.tw-open-data) 的使用原則與 [ldkrsi MIT](https://github.com/ldkrsi/cpbl-opendata/blob/master/LICENSE)。CPBL 範圍沿用本專案 [資料來源文件](../../資料來源.md)，沒有自行擴張其授權。
