現有 32 頁簡報已涵蓋官方初審要求，可作為初稿提案；本輪未發現需要重做簡報或更換模型的理由。這是內容與檔案驗收結論，不代表獲選保證，也不代表報名表單的附件規格已確認。

依[主辦方公告](https://blog.rebas.tw/articles/4136)，初審不要求完成程式或產品。評分以問題與價值、資料與方法、產品與情境各 25%，完整性與可行性 15%，創新性 10%。目前作品已有可展示原型，但尚未經真實球隊效益驗證。

## 本輪實際修正

回測驗證頁的附加診斷若缺欄位，原先會先顯示結論，再因 `variants.map` 或數值格式化而中斷。現在在繪圖前一併核對診斷、計數範圍與有限數值，並拒絕負的 MSE／MAE；無效資料顯示錯誤與重試入口。有效正式資料的結論與圖表維持原樣，腳本快取網址已更新。

新增兩項回歸測試，涵蓋七種異常診斷／誤差資料及完整正式資料。Python **84 項**、Node **155 項**通過；實際 API 驗收包含三種評估情境、三個回放打席的兩類比較、15 次三種打者慣用手配球查詢及 11 種錯誤請求拒絕。

首次在受限環境無法連上本機服務；重跑獨立 localhost 服務完成 API 驗收，測試結束後已停止該子程序。這不是瀏覽器真人使用者研究或公開網路效能測試。

網站重新在獨立 staging 封裝，再透過可回復的原子切換驗證；692 個資產、680 個 JSON 通過。模型批次與九份權重未變，資料數值驗收沿用已通過且未受本輪改動影響的紀錄。

## 簡報複查

最新正式檔為 [32 頁 PPT](../../../presentations/competition-2026/audited-20261022/一球兩面_檢查修訂版_32頁_20261022.pptx) 與同名 PDF。兩份檔案及 MP4 的 SHA-256 與上一輪逐頁、數據與引用核對的交付檔一致，本輪沒有為了製造新版本而重新輸出。

- 重新渲染 32 頁並查看四張總覽，未發現明顯裁切、重疊、異常換行或文字擁擠。這是渲染檢視，不能替代不同電腦的 PowerPoint 顯示測試。
- 逐 run 檢查中文標楷體、英文與數字 Times New Roman；無備忘稿、動畫或轉場。
- PDF 32 頁皆包含對應 PPT 全部段落；封面與結尾的網站、GitHub 超連結存在。
- 嵌入影片與獨立 MP4 完全一致。展示仍為真實 UI 截圖剪輯，不能稱為連續操作錄影；原生 PowerPoint 播放、暫停與重開檔尚未實機驗證。
- 模型改善區間跨零、觀察性結果非因果、多局規劃尚未實作等界線保留；未加入未通過穩定性檢查的完整模型區間。

## 正式送件前

1. 依使用者原要求，封面仍保留「隊名」；報名時須確定正式隊名、隊長與成員資料。參賽者為蘇櫟、陳信安。
2. 公告將繳交方式交由[報名表單](https://rebastaiwan.pse.is/9nzxad)說明。本輪工具無法讀取表單，尚未確認附件類型、大小與頁數限制；32 頁是使用者指定版本，不宣稱已符合未知表單限制。
3. PR #26 須由主要審查者合併後才會進入發布流程。公開網站先前為舊版，合併後應驗證公開模型為 v4、模型驗證 JSON 可載入及主要操作可用；本輪沒有合併或部署。
4. 報告用電腦需安裝指定字型並確認影片可播放。若初審只接受 PDF，影片不會隨 PDF 播放，請按表單允許方式附 MP4 或 Demo 連結。

驗收細節見本目錄 `summary.json`、`delivery-verification.json`、測試紀錄、API 報告與四張逐頁總覽。沒有未完成的模型訓練需要等待。
