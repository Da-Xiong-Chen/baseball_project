## 操作與版面

- 手機與桌機預設淺色，統一記分板、日期控制和候選卡片。保留深色及鍵盤操作。
- 新回放可篩選比分、壘況、調度與球員。賽果按使用者操作依序揭示。季成績與對戰資料由自訂結果的展開區載入。
- 換投結果可帶入牛棚方案 A／B，各自安排接續順位並保留容量及狀態。實際換投仍由「換上」操作。
- 代打顯示下一守備半局的接守預覽。使用期間有調度紀錄與逐次復原。已套用球隊名單沿用原本瀏覽器保存方式，可下載與匯入草稿。
- 使用實際 Edge 在 320、390、768、1280 CSS px 測試。覆蓋歷史連結、回上一頁、日期未收錄、兩次換投逐次撤回及本機名單匯出、再匯入。首頁沒有請求回放與季成績紀錄檔。
- 七個新增日期逐筆由 Python 重算，10/04 採同檔案的既有驗收。合計 3,746 組攻守視圖、1,692 筆調度標記，最大數值差 5.33×10⁻¹⁵。[逐日驗收收據](replay-verification.json)
- 本機 CI 無原始資料模式通過，涵蓋 231 項 JavaScript 測試與 61 項 Python 測試。

## 疲勞：失分三棒視窗

2026 六局起的 9,044 個可重建視窗、360 場。以賽前模型與該打席開始時的三棒構成預測，遇第三出局即停止。局勢基準及後續棒次仍會發生的機率由測試月前資料估計，同一基準加上投打相對效應，再配對比較是否加入現行先發疲勞項。以比賽配對重抽樣 2,000 次。

| 分組 | 視窗 | 局勢基準 MSE | 關閉疲勞 MSE | 開啟疲勞 MSE | 開啟減關閉的 95% 區間 |
|---|---:|---:|---:|---:|---|
| 全部 | 9,044 | 0.224463 | 0.226354 | 0.227199 | +0.000564 至 +0.001130 |
| 先發 95 球以上 | 232 | 0.173788 | 0.168956 | 0.184389 | +0.006255 至 +0.023258 |
| 實際換投後 | 1,595 | 0.207138 | 0.208858 | 0.208858 | 兩種預測相同 |

現行後援疲勞數值預設為零，連戰後援分組的開關結果相同。另以滾動 Ridge 比較實際登板單打席的負荷特徵，先發與後援的 RE24 誤差差值區間皆跨零。這一輪維持正式權重與排序。高球數的觀察樣本限實際續投且能重建視窗者。

## 其他研究與驗收

- 2026 守位來源共有 27,268 個打席，27,265 個有完整開場守備陣容。561 次代打中，238 位次可在下一防守半局開場找到接守位置。未在該局守備九人中出現的紀錄仍按實際觀測範圍解讀。 [守位覆蓋](fielding-coverage.json)
- 用 27,268 個 2026 打席核對勝率換算，月份先前資料估出的局勢斜率對觀測 WPA 的誤差低於聯盟單一斜率，MSE 0.000921 對 0.001830。另測主場勝負機率表，和局按半勝處理。 [勝率校準](win-calibration.json)
- 候選差距四級依實際未換人樣本檢查。各區間並非單調變化，保留既有 1 百分點提示門檻。 [門檻分組](gain-bins.json)
- 5 個實際連戰場景與 1 個同日第二場的假設場景，用同一容量規劃器核對打席容量、缺口、保留選手及已退場限制。 [牛棚容量](bullpen-capacity.json)

## 跨賽季與外部資料

中職公開頁面可查到 2026 二軍賽事、球員打席與投球統計。若要納入模型，需要確認逐球與球員識別的完整度、資料批次取得方式及可再利用條件。官方即時登錄與賽況也需單獨確認來源與授權。本次研究以已驗證的一軍資料重現。 [中職二軍賽事範例](https://stats.cpbl.com.tw/schedule/2026-D-231) · [Rebas 公開資料與使用原則](https://github.com/rebas-tw/rebas.tw-open-data)

新賽季可以沿用現有的每週時間切分檢查近期加權。在第一場未見樣本納入前，先鎖定模型清單、評估指標及採用門檻，再按週記錄覆蓋率、失分與校準。 [季中迭代紀錄](../season-iteration-2026/README.md)

## 重現

1. 使用已驗證的三季 Rebas 資料。以 `config/site-2026.json` 為基礎，按日期設定 `history_date`。指定隔離的 `BASEBALL_DATA_ROOT`、`BASEBALL_MODEL_DIR` 與 `BASEBALL_STATIC_OUT`。
2. 用 [月份 v5 批次](../timing-2026/)及原始資料進件清單執行 `scripts/export_single_day.py --verified-intake ... --out ...`。接著指定該日的 `BASEBALL_BATCH_CONTEXT`，用 `scripts/export_fielding_plans.py` 匯出守位備案及 `tests/verify_history_day.py` 重算數值。清單位於 [日期索引](../../data/replay/dates.json)。
3. 使用原三季設定與八權重批次重跑 `scripts/evaluate_site_fatigue_2026.py --out <新資料夾>`。其他研究可重跑 `evaluate_pitcher_workload_2026.py`、`audit_win_calibration_2026.py`、`audit_decision_gain_bins.py` 以及專案裡的守位與牛棚稽核工具。
4. 執行 `python scripts/run_ci.py --require-no-raw` 檢查靜態匯出、語法、連結與測試。已啟動本機網站時，執行 `node tests/browser_multiday.cjs` 驗收日期、分享及操作流程。
